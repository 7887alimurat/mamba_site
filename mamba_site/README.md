# Mamba — личная комната

Персональный сайт-инструмент: расписание, дедлайны, план на день, портфолио, соцсети,
быстрый вход в LMS/My-DU AITU. Бэкенд на Flask + SQLite, фронтенд — чистый HTML/CSS/JS
(без сборщиков — редактируй `static/css/style.css` и `static/js/main.js` напрямую).

## Запуск

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Открой http://127.0.0.1:5000 — при первом запуске автоматически создастся
база данных `data/mamba.db` и таблицы.

## Структура

```
app.py                 бэкенд: маршруты страниц + JSON API
templates/              Jinja2-шаблоны (base.html — общий каркас с сайдбаром)
static/css/style.css    все цвета/шрифты/отступы собраны в :root — легко перекрасить
static/js/main.js       общие JS-хелперы (fetch-обёртка, тосты, обратный отсчёт)
static/uploads/         сюда сохраняются загруженные обои (фото/gif/видео)
data/mamba.db           SQLite-база (создаётся автоматически)
```

## Что где редактировать

- **Расписание пар** — страница «Расписание», форма внизу таблицы.
- **Дедлайны/ассайнменты** — там же, блок «Дедлайны и ассайнменты»; можно
  указать прямую ссылку на нужный ассайнмент в LMS.
- **План на день** — страница «План на день», можно листать по датам через
  выбор даты сверху.
- **Портфолио** — страница «Портфолио»: название, описание, ссылка на GitHub, теги.
- **Соцсети** — страница «Соцсети»: ссылки на Instagram/TikTok/YouTube/Telegram.
- **Обои/фон, акцентный цвет, имя, приветствие, ссылки на LMS и My-DU** —
  страница «Настройки».

## Быстрый вход

Кнопки LMS и My-DU в сайдбаре ведут на `lms.astanait.edu.kz` и
`my-du.astanait.edu.kz` — ссылки можно поменять в «Настройках», если понадобится.

## Дизайн

Токены дизайна (цвета, шрифты, радиусы) — в самом верху `static/css/style.css`,
в блоке `:root`. Акцентный цвет также можно менять прямо из интерфейса
(«Настройки» → «Акцентный цвет») — он сохраняется в базу и подставляется
в шаблон при каждой загрузке страницы.
